Why Sensiloop

Every sensor, in plain words.

Hardware monitors usually show a wall of numbers. Sensiloop starts with a few clear cards, and keeps every detail one click away.

Plain-English overview

One card each for the CPU, graphics, RAM, drives, battery and network. Temperatures turn amber and red when it matters, and a badge says "All good" when it doesn't.

Every sensor, too

The All sensors page lists each core, clock, voltage and load with now, min, average and max. Tick any of them to chart them side by side.

Reports you can send

Pick the last hour, the whole day or any custom range, choose the parts and measurements, and save a PDF or an interactive web page.

Light on purpose

Built with Rust and a tiny native sensor reader. Closed to the tray it uses about 45 MB while it keeps logging every 2 seconds.

Heat alerts

Set a limit for the CPU and GPU. If either goes over, Windows shows a notification, at most once every two minutes.

Offline and private

No account, no analytics, no cloud. Your history stays in one file on your PC and anything older than 7 days is deleted.

How it works

Open it, then forget it's there.

Check your PC

Overview and All sensors

  1. Install Sensiloop and open it. Click Yes when Windows asks for admin, because temperatures need it.
  2. The Overview shows each part's temperature, usage, clock and power, plus a chart of the last 15 minutes. Hover the chart for exact values, drag to zoom.
  3. Open All sensors for every reading, grouped by part. Search, filter by type, and tick sensors to chart them.
  4. Close the window when you're done. Sensiloop keeps logging in the tray. Right-click the tray icon and pick Quit to stop.

Make a report

The Reports page

  1. Pick a time range: the last 15 minutes, hour, 6 hours or 24 hours, since the PC started, everything recorded, or a custom start and end.
  2. Tick the parts (CPU, GPU, RAM…) and the measurements (temperatures, usage, clocks, power…) you want.
  3. Press Save as PDF or Save as web page. You get highlights like the hottest moment, a chart per measurement, and a table of min, average and max.
What it reads

Reads everything, changes nothing.

Reads

  • CPU temperature, and each core's load, clock, power and voltage
  • GPU temperature, hot spot, load, clocks, power and video memory
  • RAM use and memory-stick temperatures
  • SSD and hard drive temperatures, space and activity
  • Battery charge, charge rate and wear
  • Network upload and download speed, and fans when your PC exposes them

Never does

  • Change clocks, fan curves or any hardware setting
  • Send anything over the internet
  • Ask you to sign up or sign in
  • Keep history longer than 7 days
  • Keep running after you pick Quit
  • Run ads or upsells

Questions

Why does my CPU temperature show "—"?

Sensiloop reads CPU temperature, fans and voltages through PawnIO, a small free signed driver. The installer offers to install it. If you skipped that, open Sensiloop and click Get PawnIO on the banner, install it, then restart Sensiloop.

Why does Windows say "unknown publisher"?

Code-signing certificates cost money each year, and Sensiloop is free, so it isn't signed. Windows SmartScreen warns about any unsigned app. Click More info › Run anyway. The full source is on GitHub if you want to check or build it yourself.

Why does it ask for admin rights?

Windows only lets admin apps read hardware sensors like CPU temperature and voltages. Sensiloop only reads them. It never changes clocks, fans or any setting.

Does it keep running when I close it?

Yes. Closing the window sends Sensiloop to the tray, where it keeps logging using about 45 MB. Right-click the tray icon and pick Quit to stop it. It only records while it's running, and reports show how much of the chosen time was recorded.

How much history does it keep, and where?

The last 7 days, in one file under %APPDATA%\com.sensiloop.app. Older readings are deleted automatically, and you can delete everything from Settings.

Why can't I see my fans?

Many laptops don't share fan speeds with Windows apps. If your PC exposes them, they show under Fans & cooling. If not, that option stays greyed out.

Does it send anything over the internet?

No. Sensiloop has no analytics, no account and no cloud. Reports are saved where you choose and only leave your PC if you send them.
